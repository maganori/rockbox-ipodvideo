# rockbox-ipodvideo

Rockbox の個人用カスタムフォーク。主に iPod Video（5/5.5世代）向けにビルドして使う。
2011年頃に使っていた自前パッチ一式を、現在の上流（Rockbox/rockbox）に合わせて移植したもの。
カスタマイズは `ipodvideo-custom` ブランチに入っている。

## 適用しているパッチ

| # | 内容 | コミット | 対象範囲 |
|---|------|---------|---------|
| 1 | ボタンのリピート開始を 300ms → 600ms（元パッチ 00） | da0ed4835 | 全ターゲット共通 |
| 2 | dircache 拡大（予約 64KB→256KB、上限 6MB→12MB）。ファイル数の多い大容量ライブラリ向け（元パッチ 01） | b5f6148a9 | 全ターゲット共通 |
| 3 | 「ホールドスイッチで電源オフ」設定を追加（充電中は発動しない）（元パッチ 12） | 3397517ad | 全ターゲット共通 |
| 4 | アラームの残差分（2分未満でも設定可、表示を設定時刻に）（元パッチ 11） | 49ec24f55 | 全ターゲット共通 |
| 5 | PP502x QuickBoost（CPU 周波数切替を PLL_CONTROL 変更のみに高速化）（元パッチ 14） | 032d7b68f | PP502x 系全体（iPod 4G/Photo/mini/nano 1G 等にも効く） |
| 6 | フォントバッファ上限を 2MB に（MEMORYSIZE>4 の場合）（元パッチ 02） | 8d86e3bf8 | 全ターゲット共通 |
| 7 | UI フォント 15/19 を日本語フォント（SHG30P）に差し替え | ab4847a31 | fonts/ 共通資産 |

| 9 | システムフォントに日本語フォント（rockbox_default）を採用 | c665fbf81 | ipodvideo 向けビルドのみ |
| 10 | 起動ロゴの表示位置を全画面に（y=10→0）（元パッチ 04） | 85f3b242a | 全ターゲット共通 |

| 12 | シミュレータの充電シミュレーション高速化＋ charge_state 遷移（元パッチ 13） | 8aeba4787 | シミュレータ専用 |

## iFlash 等のストレージ換装について

- このフォークには、iFlash をはじめとする SD/CF アダプタ向けの互換性対策は**入っていない**。大容量ドライブやアダプタの動作は上流 Rockbox の対応範囲に依存する
- 大容量化でファイル数が増えた場合に効く変更として、dircache の上限拡大（#2）は入っている
- 動作確認は純正 HDD（80GB）環境でのみ行っている
